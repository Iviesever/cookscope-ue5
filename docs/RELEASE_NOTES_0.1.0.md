# CookScope 0.1.0 Release Notes

Status: local source-only Alpha candidate; no GitHub Release has been published.

## Included

- UE 5.8 Editor plugin with usable Slate audit tab.
- Strict Core snapshot/rule schemas and deterministic typed dependency graph.
- Configurable P0 naming, path, dependency, resource, Asset Manager, Cook, and aggregate budget rules.
- Real Development Asset Registry size merge and baseline/candidate diff.
- JSON, SARIF 2.1.0, JUnit XML, and offline responsive HTML.
- Data Validation integration and strict Commandlet exits `0/2/3/4/5`.
- Twenty deterministic project fixtures, real baseline/candidate Cook examples, local BuildPlugin and extraction scripts.

## Release policy

The eventual `v0.1.0` GitHub Release must be generated from an annotated tag and contain source only with zero uploaded binary assets. Packaged plugins, archives, logs, screenshots used only as evidence, and Cook output remain local ignored artifacts.

See [known limitations](KNOWN_LIMITATIONS.md) before adoption.
